# Лексико-грамматический на двух языках

С помощью лексико-грамматического поиска можно искать последовательность лексем и/или словоформ, обладающих определенными грамматическими и/или семантическими характеристиками.

{% note info %}

Данный режим поиска представлен в параллельных двуязычных корпусах

{% endnote %}

## Структура поискового запроса

Заполнение формы запроса на двух языках аналогично обычному лексико-грамматическому запросу. Ключевое отличие заключается в том, что для каждого языка необходимо заполнить свой раздел, указав код языка внутри `FormSection`.

В [описании](common-format.md#formsectionvalue) структуры запроса упоминалось, что разные формы используют разную схему заполнения `FormSectionValue`.

## Пример

Пример запроса в английском корпусе для слов cat и кот

```json
{
  "paraLexGramm": {
    "sectionValues": [
      {
        "conditionValues": [
          {
            "fieldName": "lang_search",
            "text": {
              "v": "eng"
            }
          }
        ],
        "subsectionValues": [
          {
            "conditionValues": [
              {
                "fieldName": "lex",
                "text": {
                  "v": "cat"
                }
              }
            ]
          }
        ]
      },
      {
        "conditionValues": [
          {
            "fieldName": "lang_search",
            "text": {
              "v": "rus"
            }
          }
        ],
        "subsectionValues": [
          {
            "conditionValues": [
              {
                "fieldName": "lex",
                "text": {
                  "v": "кот"
                }
              }
            ]
          }
        ]
      }
    ]
  },
  "params": {
    "pageParams": {
      "page": "0",
      "docsPerPage": "10",
      "snippetsPerPage": "50",
      "snippetsPerDoc": "10"
    },
    "sampling": "0",
    "noDiacritic": true
  },
  "corpus": {
    "type": "PARA",
    "lang": "eng"
  }
}
```
